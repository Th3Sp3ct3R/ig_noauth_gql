What to collect

Every field is scraped anyway (it costs the same two requests per account); the ticks decide what goes into the export and the results table. Change them any time and re-download.

Posts

Post 1 is the newest. Accounts that hide like counts get “hidden”; accounts with fewer posts leave the rest empty. Applies to runs started after you change it.

Connections

One IP gets roughly 300 requests (about 145 accounts) before Instagram blocks it for a few hours. The scraper works through the enabled connections in turn, switches when one gets blocked and rests blocked ones for three hours. Add a rotating mobile or residential proxy to run without stopping.

OnProxyRotate-IP linkStatus

Test sends one real request through the connection (costs one call). A connection that fails is skipped until it passes a Test again; a blocked one comes back by itself after three hours. For SOCKS proxies run pip install requests[socks] once.

File import: one proxy per line, e.g. http://138.199.35.215:9002 or socks5h://user:pass@host:port. A scheme is added automatically if missing. Add a rotate-IP link after a comma or tab on the same line if you have one. Lines starting with # and duplicates of proxies already in the pool are skipped.
